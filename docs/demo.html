AI 的回答常常加了客套、重述和一大堆細節；可以要求它先給答案、最多三點。

這是「一看就懂」技能包的示範頁。滑鼠移到框或箭頭上看細節（手機點一下）；卡片點開看更多。

重點一：長不等於有用

開場白、重述問題、「總而言之」這些字，讀的人要花時間，對答案沒有幫助。

重點二：短也要留住重要的東西

數字、「不」「沒有」這類否定詞、會出事的風險，不能為了短就拿掉。

重點三：複雜的就畫出來

文字講不清楚的，簡單的在對話裡畫，複雜的做成一頁像這樣的網頁。

數字都是輸出 token，都不是本技能包的實測。來源：caveman 早期 README 與其 HONEST-NUMBERS 說明；Kuba Guzik 的獨立測試（Medium）。
